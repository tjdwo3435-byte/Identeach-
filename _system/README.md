# 프로그램 입력 시스템

**시트 탭 하나 = 프로그램 하나.** 한 화면에서 그 프로그램의 모든 정보를 채웁니다.
채운 내용은 홈페이지에 자동으로 올라가고, 블로그 글과 제안서를 쓸 때도 그대로 씁니다.

```
구글 시트에서 탭 채우기
      ↓  sync        시트 통째로 받아오기
      ↓  form-to-data 폼 → 데이터
      ↓  build       미리보기 만들기
   눈으로 확인
      ↓  build --apply + git push
identeach.co.kr 반영
```

---

## 프로그램 만드는 사람 (직원 누구나)

시트만 채우면 됩니다. 프로그램 하나 = 탭 하나입니다.

1. **[_읽어보기]** 탭을 먼저 봅니다 — 규칙과 각 칸이 어디에 나오는지 정리돼 있습니다.
2. **[_예시]** 탭을 봅니다 — 다 채워진 예시(미니 스포츠데이)입니다. 이대로 따라 쓰면 됩니다.
3. **[_양식]** 탭에서 마우스 오른쪽 → **복사본 만들기**
4. 새 탭 이름을 프로그램 이름으로 바꿉니다
5. 왼쪽 항목 이름을 보고 오른쪽 칸을 채웁니다. 맨 오른쪽 회색 글씨가 각 칸 설명입니다.
6. 맨 위 **사용** 칸에 `O` 를 적으면 홈페이지에 올라갑니다. 아직이면 비워두세요.

채울 때 지킬 것:

- 밑줄(`_`)로 시작하는 탭은 안내용입니다. 건드리지 마세요.
- **주소(ID)** 는 프로그램마다 달라야 합니다. 겹치면 나중 것이 덮어씁니다.
- 칸 안에서 줄 바꾸기는 **Alt+Enter**
- 칸 맨 앞에 작은따옴표를 쓰려면 **두 번**(`''`) 치세요. 한 번만 치면 구글 시트가 먹습니다.
- 표에서 빈 줄은 그냥 두면 됩니다. 알아서 건너뜁니다.
- 사진은 **파일 이름만** 적습니다. 폴더는 위쪽 `사진폴더` 칸에 한 번만.

**10번 섹션(제안서·블로그용)은 홈페이지에 안 나옵니다.** 비워도 홈페이지는 정상으로 만들어집니다.
다만 여기를 채워두면 제안서 쓸 때, 블로그 글 쓸 때 그대로 꺼내 쓸 수 있습니다.

## 홈페이지에 올리는 사람

```bash
python _system/sync.py           # 구글 시트 통째로 받아오기
node _system/form-to-data.js     # 폼 → 데이터 (이상한 점이 있으면 여기서 알려줌)
node _system/build.js            # 미리보기 생성 (실제 사이트는 그대로)
```

`_system/_build/` 안의 결과를 브라우저로 열어 확인한 뒤:

```bash
node _system/build.js --apply
git add -A && git commit -m "프로그램 추가: 이름" && git push
```

1~2분 뒤 identeach.co.kr 에 반영됩니다.

원본과 어긋난 곳이 없는지 확인하려면:

```bash
node _system/verify.js         # 항목 단위 대조
node _system/verify-cards.js   # 목록 카드 대조
```

## 처음 한 번만 하는 준비

### 1. 시트를 구글 드라이브에 올리기

`_system/data/아이덴티치_프로그램_입력시트.xlsx` 를
**기억x아이덴티치 쉐어 폴더 > 4.홈페이지 프로그램 마스터** 에 끌어다 놓습니다.
구글 시트로 변환하면 탭이 그대로 살아납니다.

> 드라이브 API 로는 탭이 여러 개인 시트를 만들 수 없어, 이 한 번만 손으로 올려야 합니다.

### 2. 웹에 게시

시트에서 **파일 > 공유 > 웹에 게시**
→ **전체 문서** 선택
→ 형식을 **Microsoft Excel(.xlsx)** 선택 → 게시

나오는 주소를 `_system/sheet.config.json` 의 `게시주소` 에 넣습니다.

> 전체 문서를 통째로 게시하기 때문에 **주소는 하나뿐**입니다.
> 나중에 탭(프로그램)을 아무리 추가해도 이 설정을 다시 손댈 일이 없습니다.
> 로그인·인증키도 필요 없습니다.

### 3. 확인

```bash
python _system/sync.py
node _system/form-to-data.js
node _system/verify.js
```

`내용 손실 0건` 이 나오면 시트가 원본과 같다는 뜻입니다.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `form-schema.json` | **입력 폼의 항목 정의 — 항목을 바꾸려면 여기만** |
| `make-form.py` | 스키마 + 현재 데이터 → 입력용 엑셀 만들기 |
| `sync.py` | 게시된 구글 시트 통째로 받아오기 |
| `xlsx-to-tabs.py` | 엑셀 → 탭별 CSV |
| `form-to-data.js` | 폼 탭 → 빌드용 데이터 + `program-info.json` |
| `build.js` | 데이터 → 상세 페이지 + 목록 + sitemap |
| `template.html` | 페이지 껍데기 — **디자인 바꾸려면 여기** |
| `schema.js` | 데이터 표 정의와 변환 규칙 |
| `verify.js` `verify-cards.js` | 검증 |
| `data/program-info.json` | **제안서·블로그·AI 용 전체 정보** |
| `data/tabs/` | 시트에서 받아온 탭별 원본 |
| `data/sheet/` | 빌드가 먹는 평면 표 |
| `_build/` | 미리보기 결과 |

`extract.js` `extract-cards.js` `to-sheet.js` `make-template.js` `css-compare.js` `shell-compare.js`
는 기존 페이지에서 데이터를 뽑아낼 때 쓴 최초 1회용 도구입니다. 이미 실행됐습니다.

## 주의할 점

- `build.js` 는 **`--apply` 를 붙여야만** 실제 사이트를 고칩니다.
- 디자인(CSS)을 바꾸려면 `template.html` 하나만 고치면 **모든 프로그램 페이지에 한꺼번에** 적용됩니다.
- 구형 3개(`진로 토크쇼`·`미래직업연구소`·`내 인생의 CEO`)는 옛 구조라 `사용` 을 꺼둔 상태입니다.
  그대로 두면 기존 페이지가 유지됩니다.
- 탭을 왼쪽으로 끌면 **목록 페이지에서도 앞으로 나옵니다.** 탭 순서 = 노출 순서입니다.
