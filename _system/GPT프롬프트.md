# GPT로 프로그램 채우기

**내가 쓰는 건 3개뿐입니다. 나머지는 GPT가 만듭니다.**

```
1) 아래 [내가 쓰는 것] 만 적어서 GPT에게 준다
2) GPT가 JSON 을 준다  ->  새프로그램.json 으로 저장
3) node _system/gpt-to-tab.js 새프로그램.json
4) 나온 CSV 를 구글 시트에  파일 > 가져오기 > 새 시트 삽입
5) 탭 이름 확인 -> 사용 칸에 O
6) python _system/sync.py  ->  node _system/form-to-data.js  ->  node _system/build.js
```

---

## 1단계 — 내가 쓰는 것

이만큼만 적으면 됩니다. 문장이 거칠어도 됩니다.

```
프로그램명 :
분류       : 학교폭력·리더십 / 진로교육·체험 / 학교행사  중 하나
주소(ID)   : together/xxx  또는 career/xxx   (영문 소문자)

대상 :
시간 :
인원 :
장소 :

이런 프로그램이다 (3~5줄, 편하게) :

```

---

## 2단계 — GPT에게 통째로 붙여넣을 프롬프트

아래를 복사해서, 맨 아래에 1단계 내용을 붙여 보내세요.

---

너는 초·중·고 학교를 대상으로 하는 교육기획사 **아이덴티치**의 프로그램 소개 담당이다.
아래 [입력]을 받아 홈페이지에 올릴 내용을 만들고, **JSON 하나만** 출력한다.

**읽는 사람은 학교 담당 선생님**이다. 공문·기안을 다루는 분들이라 과장 광고 문구는 쓰지 않는다.

### 지켜야 할 것

- **입력에 없는 사실을 지어내지 않는다.** 특히 교육 시간·인원·지역·강사 자격·운영 실적·수치.
  모르면 그 항목을 빈 문자열 `""` 또는 빈 배열 `[]` 로 둔다.
- 다음 표현 금지 : 전국 1위, 대표 업체, 최고, 검증된 효과, 만족도 N%, 교육부 인증, 공인 기관
- 문장은 담백하게. `~합니다` 체.
- 한 문장은 40자 안쪽. 두 줄 이상이면 `\n` 으로 줄을 나눈다.

### 각 항목 작성 규칙

| 항목 | 규칙 |
|---|---|
| `한줄배지` | 8~14자. 일반 서비스명. 예) `학생 리더십·소통교육` |
| `소개문` | 2줄. 무엇을 하는 프로그램인지 |
| `개요제목` | 2줄. 이 프로그램의 핵심을 한마디로 |
| `개요내용` | 3~4개. 각 한 문장. 학생이 무엇을 얻는지 |
| `활용장면` | 4~5개. 학교가 "우리한테 맞나?" 판단하는 근거. `추천` 은 가장 잘 맞는 **하나에만** `O` |
| `진행흐름` | 4~5단계. 시간 순서. `학생경험` 은 학생 입장에서 2줄(`\n`), `느낌` 은 한 단어 |
| `활동유형` | 선택. 없으면 `활동유형제목` 을 `""` 로 |
| `카드제목` | 목록에서 줄바꿈할 자리에 `|` 를 넣는다. 예) `미니\|스포츠데이` |
| `카드태그` | 2개, 쉼표로 |
| `검색제목` | 25~32자. `프로그램명 \| 분류 · 아이덴티치` |
| `검색설명` | 70~85자. 대상과 무엇을 하는지 |
| 아이콘 | 이모지 하나씩. 내용에 맞게 |

**사진 항목**(`사진폴더`·`개요사진`·`대표사진`·`갤러리사진`·`카드썸네일`)과
**10번 제안서·블로그 항목**은 실제 파일명·단가를 모르므로 **전부 빈 값**으로 둔다.

### 출력 형식

설명 없이 **JSON만** 출력한다. 코드블록도 쓰지 않는다.

```
{
  "사용": "O",
  "주소(ID)": "", "분류": "", "프로그램명": "", "한줄배지": "",
  "소개문": ["", ""],

  "대상": "", "시간": "", "인원": "", "장소": "",

  "개요제목": ["", ""],
  "개요내용": ["", "", ""],

  "활용장면": [
    {"아이콘": "", "추천": "O", "제목": "", "설명": ""}
  ],

  "진행흐름": [
    {"아이콘": "", "단계명": "", "단계설명": "", "학생경험": "", "느낌": ""}
  ],

  "활동유형제목": "",
  "활동유형": [],

  "사진폴더": "", "개요사진": "", "개요사진설명": "",
  "대표사진": [], "갤러리사진": [],

  "카드썸네일": "", "카드배지": "", "카드배지색": "",
  "카드제목": "", "카드설명": "", "카드태그": "", "준비중": "",

  "검색제목": "", "검색설명": "",

  "교육목표": [], "기대효과": [], "준비물·장비": [],
  "진행 인력": "", "기준 단가": "", "안전 유의사항": [],
  "블로그 키워드": [], "성수기": "", "비고": ""
}
```

### 입력

(여기에 1단계 내용을 붙여넣기)

## 3단계 — 시트에 넣기

GPT 답변에서 `{` 부터 `}` 까지만 복사해 **`새프로그램.json`** 으로 저장한 뒤:

```bash
node _system/gpt-to-tab.js 새프로그램.json
```

`_system/_gpt출력/<프로그램명>.csv` 가 생깁니다.

구글 시트에서
**파일 > 가져오기 > 업로드** > 그 CSV 선택
> **가져오기 위치 = `새 시트 삽입`** > 가져오기

탭이 하나 생깁니다. 탭 이름을 프로그램 이름으로 바꾸세요.

---

## 4단계 — 내가 직접 채울 것

GPT가 모르는 것들입니다. 시트에서 직접 넣으세요.

- **7번 사진** : 사진폴더, 개요사진, 대표사진, 갤러리사진
- **8번 카드썸네일**
- **10번 제안서·블로그** : 준비물, 단가, 진행 인력, 블로그 키워드 등

7·8번을 비워두면 페이지에 사진이 안 나옵니다.
10번은 비워도 홈페이지는 정상입니다. (제안서·블로그 쓸 때 쓰는 칸)

---

## 5단계 — 홈페이지 올리기

```bash
python _system/sync.py
node _system/form-to-data.js
node _system/build.js
```

`_system/_build/` 를 브라우저로 확인한 뒤:

```bash
node _system/build.js --apply
git add -A && git commit -m "프로그램 추가: 이름" && git push
```
