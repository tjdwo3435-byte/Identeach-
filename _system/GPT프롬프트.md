# 프로그램 하나 올리기 — 7줄만 적으면 됩니다

프로그램 1개를 시트에 다 채우려면 **84칸**입니다.
그중 **대표님만 아실 수 있는 건 7가지**뿐입니다. 나머지 77칸은 GPT와 제가 만듭니다.

```
84칸
├─  7  대표님이 적는 것        ← 이 문서
├─ 60  GPT가 쓰는 글
├─ 11  사진 파일명            ← 사진 정리한 뒤에
└─  6  이미 정해진 공통값       ← 자동
```

---

## 흐름

```
① 아래 7줄을 적는다
② GPT에게 [프롬프트] + 7줄을 붙여넣는다
③ GPT가 준 JSON 전체를 클로드코드에 붙여넣는다
④ 끝 — 검증·등록·빌드·배포는 제가 합니다
```

---

## ① 대표님이 적는 7줄

```
1. 프로그램명 :
2. 분류       : 학교폭력·리더십 / 진로교육·체험 / 학교행사   (하나 고르기)
3. 대상       : 예) 중학교 1~3학년
4. 시간       : 예) 2교시(100분)
5. 인원       : 예) 최대 한 학년
6. 장소       : 예) 강당 또는 교실

7. 어떤 프로그램인가 (편하게 5~10줄. 아래 세 가지가 들어가면 좋습니다)
   - 무엇을 하는 활동인지
   - 진행 순서 (1교시 → 2교시 → …)      ★ 이게 제일 중요합니다
   - 학교가 주로 어떤 상황에서 찾는지
```

### ★ 진행 순서를 꼭 적어주세요

GPT가 **가장 잘 지어내는 항목**입니다. 안 적으면 그럴듯한 가짜 순서를 만들어 냅니다.
홈페이지에 실제와 다른 진행표가 올라가면, 학교에서 그걸 보고 기안을 올립니다.

거칠어도 됩니다. 이 정도면 충분합니다.

```
1교시  아이스브레이킹 하고 팀 나눔
2교시  본 활동
3교시  발표하고 사진 찍고 마무리
```

---

## ② GPT에게 붙여넣을 프롬프트

아래 ─── 안쪽을 복사하고, 맨 끝에 ①의 7줄을 붙여서 보내세요.

────────────────────────── 여기부터 복사 ──────────────────────────

너는 초·중·고 학교를 대상으로 하는 교육기획사 **아이덴티치**의 프로그램 소개 담당이다.
아래 [입력]을 받아 홈페이지에 올릴 내용을 만들고 **JSON 하나만** 출력한다.

**읽는 사람은 학교 담당 선생님**이다. 공문·기안을 다루는 분들이라 광고 문구는 통하지 않는다.

## 절대 규칙

- **입력에 없는 사실을 지어내지 않는다.** 특히 교육시간·인원·지역·강사 자격·운영 실적·만족도·수치.
  모르면 빈 문자열 `""` 또는 빈 배열 `[]` 로 둔다. **추측해서 채우지 마라.**
- **진행흐름은 입력에 적힌 순서만 쓴다.** 입력에 없으면 `[]` 로 둔다. 만들어내지 마라.
- 금지 표현 : 전국 1위, 대표 업체, 최고, 검증된 효과, 만족도 N%, 교육부 인증, 공인 기관, 전문 강사진
- `~합니다` 체. 한 문장 40자 안쪽. 두 줄이면 `\n` 으로 나눈다.

## 항목 규칙

| 항목 | 규칙 |
|---|---|
| `한줄배지` | 8~14자. 예) `학생 리더십·소통교육` |
| `소개문` | 2줄. 무엇을 하는 프로그램인지 |
| `개요제목` | 2줄. 핵심을 한마디로 |
| `개요내용` | 3~4개. 각 한 문장. **학생이 무엇을 얻는지** |
| `활용장면` | 4~5개. 학교가 "우리한테 맞나" 판단하는 근거. `추천` 은 가장 잘 맞는 **하나에만** `O` |
| `진행흐름` | 입력의 순서 그대로. `학생경험` 은 학생 입장 2줄(`\n`), `느낌` 은 한 단어 |
| `카드제목` | 목록에서 줄바꿈할 자리에 `\|`. 예) `미니\|스포츠데이` · 쉼표가 있으면 쉼표를 앞에 붙인다 `스쿨핑,\|텐트밖은 스쿨` |
| `카드태그` | 2개, 쉼표로 |
| `검색제목` | `프로그램명 \| 분류 · 아이덴티치` |
| `검색설명` | 70~85자. 대상과 무엇을 하는지 |
| 아이콘 | 이모지 하나씩 |

**사진 항목과 제안서 항목은 전부 빈 값**으로 둔다. 파일명·단가를 모르기 때문이다.

## 출력

설명 없이 JSON만. 코드블록도 쓰지 않는다.

```
{
  "사용": "O",
  "주소(ID)": "", "분류": "", "프로그램명": "", "한줄배지": "",
  "소개문": ["", ""],
  "대상": "", "시간": "", "인원": "", "장소": "",
  "개요제목": ["", ""],
  "개요내용": ["", "", ""],
  "활용장면": [{"아이콘": "", "추천": "O", "제목": "", "설명": ""}],
  "진행흐름": [{"아이콘": "", "단계명": "", "단계설명": "", "학생경험": "", "느낌": ""}],
  "활동유형제목": "", "활동유형": [],
  "사진폴더": "", "개요사진": "", "개요사진설명": "",
  "대표사진": [], "갤러리사진": [],
  "카드썸네일": "", "카드배지": "", "카드배지색": "",
  "카드제목": "", "카드설명": "", "카드태그": "", "준비중": "",
  "검색제목": "", "검색설명": "",
  "준비물·장비": "", "진행 인력": "", "비고": ""
}
```

`주소(ID)` 는 비워도 된다. `분류` 가 학교폭력·리더십이면 `together/`, 진로교육·체험이면 `career/` 로 시작하는 영문 소문자 주소를 제안해도 좋다.

(여기에 7줄 붙여넣기)

## ③ 받은 JSON을 저에게

GPT 답변에서 `{` 부터 `}` 까지 통째로 복사해서 대화창에 붙여넣으세요.
파일로 저장하실 필요 없습니다.

**제가 붙이기 전에 검사하는 것**

| 검사 | 왜 |
|---|---|
| 없는 사실을 지어냈는가 | 인원·시간·실적이 입력에 없는데 채워져 있으면 지웁니다 |
| 진행흐름이 입력과 같은가 | 다르면 반영 안 하고 먼저 알려드립니다 |
| 금지 표현이 있는가 | 「전문 강사진」 같은 게 섞여 들어옵니다 |
| 주소(ID)가 겹치는가 | 기존 페이지를 덮어쓰지 않도록 |
| 카드제목 세로줄 위치 | 목록 카드가 이상하게 잘리지 않도록 |

문제가 있으면 **반영하지 않고 먼저 보고**드립니다.

## ④ 그다음 제가 하는 것

```
JSON → 시트 형식 CSV 생성
     → 로컬 반영 후 미리보기 링크 전달       ← 여기서 확인하세요
     → 확인되면 빌드·배포
     → 같은 CSV를 시트에 넣을 파일로 드림     ← 시트도 최신으로
```

**시트에 직접 쓰지는 못합니다.** 구글 연결로 읽을 수는 있는데 칸에 값을 넣는 건 안 됩니다.
그래서 마지막에 **가져오기용 CSV**를 드립니다. 시트에서
`파일 > 가져오기 > 업로드 > 새 시트 삽입` 한 번만 눌러주시면 시트도 맞춰집니다.

이걸 안 하시면 다음에 `sync.py` 를 돌릴 때 시트 내용이 홈페이지를 덮어써서
방금 올린 프로그램이 사라집니다. **꼭 해두세요.**

## 자동으로 채워지는 것 (안 적으셔도 됩니다)

이미 정해져 있어서 매번 쓸 필요가 없습니다.

```
준비물·장비   PPT 진행이 기본. 강당이면 빔프로젝터 필요.
             강당 음향이 어려우면 저희가 음향 장비를 가져가며
             이 경우 추가 비용이 발생할 수 있습니다.

진행 인력     프로그램에 따라 다르지만 최소 2명.
             규모가 크면 학급마다 강사 + 메인 강사 1명.
```

이 두 개가 프로그램마다 다르면 그때만 적어주세요.

사진 칸 11개는 **드라이브 정리가 끝난 뒤**에 제가 자동으로 채웁니다.
사진 없이도 페이지는 올라갑니다. 글이 먼저고 사진은 나중에 붙이면 됩니다.
