# 입력한 내용이 어디에 나오는가

시트에 적은 글자가 실제로 어디에 찍히는지 그림으로 정리했습니다.
**[_예시] 탭(미니 스포츠데이)** 을 옆에 띄워놓고 같이 보시면 가장 빠릅니다.

---

## 2. 프로그램 목록 페이지

`identeach.co.kr/together` 에 뜨는 네모 카드입니다.

```
┌────────────────────┐
│ ┌────────────────┐ │
│ │                │ │  ← 카드썸네일
│ │   [ 사 진 ]     │ │
│ │  ⌈학기초 추천⌋   │ │  ← 카드배지  (카드배지색 을 '주황' 으로 하면 주황)
│ └────────────────┘ │
│                    │
│  미니               │  ← 카드제목 — 미니|스포츠데이 처럼
│  스포츠데이          │     | 를 넣으면 그 자리에서 줄이 바뀜
│                    │
│  팀 스포츠 미션을    │  ← 카드설명
│  통해 협력과…        │
│                    │
│  [리더십캠프][단합활동]│  ← 카드태그 (쉼표로 구분)
│  자세히 보기 →       │
└────────────────────┘
```

**카드 순서 = 시트의 탭 순서**입니다. 탭을 왼쪽으로 끌면 목록에서도 앞으로 나옵니다.

## 3. 검색결과와 카카오톡 공유

```
네이버·구글 검색결과                       카카오톡으로 링크를 보내면
┌──────────────────────────────┐        ┌──────────────────────────┐
│ 미니 스포츠데이 | 학교폭력·리더십 │        │ ┌──────────────────────┐ │
│ · 아이덴티치                   │ ←검색제목│ │   [ 대표사진 첫 장 ]    │ │
│ identeach.co.kr/together/…    │        │ └──────────────────────┘ │
│ 리더십캠프·단합프로그램에 최적화된 │ ←검색설명│  미니 스포츠데이 | …      │
│ 스포츠 미션 프로그램. 창의적…    │        │  리더십캠프·단합프로그램에…│
└──────────────────────────────┘        └──────────────────────────┘
```

`검색제목`·`검색설명` 은 **학교 선생님이 검색창에 칠 만한 말**을 넣는 게 핵심입니다.
프로그램 이름만 적으면 이름을 아는 사람만 찾아옵니다.

## 4. 블로그·제안서 (10번 섹션)

10번 섹션은 홈페이지에 **안 나옵니다.** 대신 빌드할 때
`_system/data/program-info.json` 이라는 정리본이 같이 만들어집니다.
제안서를 쓰거나 블로그 글감을 잡을 때, AI에게 이 파일을 주면 프로그램을 정확히 이해합니다.

| 시트 항목 | 어디에 쓰이나 |
|---|---|
| `교육목표` | 제안서 첫 장 '사업 목적'. 학교 공문·계획서 문구로 그대로 씁니다 |
| `기대효과` | 제안서 '기대효과' 항목. 블로그 글 마무리 문단 |
| `준비물·장비` | 제안서 '운영 계획', 학교와 사전 협의할 때 체크리스트 |
| `진행 인력` | 견적 산출 근거 |
| `기준 단가` | 견적의 출발점 |
| `안전 유의사항` | 제안서 '안전관리 계획' — 요즘 학교가 꼭 봅니다 |
| `블로그 키워드` | 블로그 글 제목·본문에 넣을 검색어 |
| `성수기` | 블로그를 언제 발행할지 정하는 기준 (성수기 1~2달 전) |

예를 들어 미니 스포츠데이의 `성수기` 가 `3~4월, 9월` 이고
`블로그 키워드` 가 `중학교 레크리에이션, 리더십캠프` 라면
→ **2월과 8월에 그 키워드로 블로그 글을 올리는 것**이 맞습니다.

## 다 채우면 이렇게 흘러갑니다

```
        ┌─ 홈페이지 상세 페이지  (1~9번 섹션)
        │
시트 탭 ─┼─ 목록 카드           (8번 섹션)
 하나    │
        ├─ 검색결과·카톡 공유    (9번 섹션)
        │
        └─ program-info.json ─┬─ 제안서 초안
                              ├─ 블로그 글감·키워드
                              └─ AI 가 프로그램을 이해하는 근거
```

한 번 채워두면 **직원 누구든** 그 프로그램을 같은 수준으로 설명할 수 있고,
홈페이지·블로그·제안서가 서로 어긋나지 않습니다.
